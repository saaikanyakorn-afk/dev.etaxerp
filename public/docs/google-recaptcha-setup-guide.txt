===============================================================
  Google reCAPTCHA - Easy Setup Guide (Getting API Keys)
  Prepared for: พี่ช้าง / E-Tax Center Team
  Date: March 12, 2026
===============================================================

STEP 1: Go to the reCAPTCHA Admin Console
   - Open your browser and go to:
     https://www.google.com/recaptcha/admin
   - Sign in with your Google account
     (use the company Google account if you have one)

STEP 2: Register a New Site
   - Click the "+" button (Create) at the top
   - Fill in the form:

     * Label: Give it a name you'll remember
       Example: "E-Tax Center" or "etaxcenter.com"

     * reCAPTCHA Type: Choose one
       - reCAPTCHA v2 → "I'm not a robot" checkbox (easiest)
       - reCAPTCHA v2 → Invisible (no checkbox, auto-detects)
       - reCAPTCHA v3 → Score-based (no user interaction, returns 0-1 score)
       Recommendation: reCAPTCHA v2 "I'm not a robot" for simplicity

     * Domains: Add your website domains
       Example:
         etaxcenter.com
         www.etaxcenter.com
         localhost  (for testing)

     * Owners: Your email is auto-added. Add team members if needed.

   - Accept the Terms of Service
   - Click "Submit"

STEP 3: Get Your Keys
   After submitting, you'll see TWO keys:

   * Site Key (public)
     - This goes in your website's frontend code
     - Safe to expose publicly
     - Looks like: 6LcXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX

   * Secret Key (private)
     - This goes in your server/backend code
     - NEVER share this publicly
     - Looks like: 6LcXXXXXXXXXXXXXXXXXXXXXXXXXXXXXX

   >>> SAVE BOTH KEYS somewhere safe! <<<

STEP 4: Copy the Keys
   - Click the "Copy site key" button
   - Store it in a safe place (password manager, secure note)
   - Click the "Copy secret key" button
   - Store it separately, securely

STEP 5: Done!
   That's it! You now have your reCAPTCHA API keys.
   Give the keys to your developer to integrate into the website.

===============================================================
  TIPS
===============================================================

  - You can register multiple sites under the same Google account
  - You can change the reCAPTCHA type later if needed
  - The admin console shows analytics (how many challenges, pass rate)
  - If you lose your keys, go back to the admin console to find them
  - For testing on localhost, make sure to add "localhost" to the domains list
