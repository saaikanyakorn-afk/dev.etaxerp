ENTRY #001 — expenses table: 3 new columns
Date: 2026-05-05/06
Status: PENDING (dev DB has columns, production does NOT)
Approved by: (waiting)
========================================================

WHAT:
  Three new columns added to the `expenses` table.

WHY:
  Feature: foreign currency support + outstanding balance display
  for expense module.
  - currency_code: store original foreign currency (USD, EUR, etc.)
  - exchange_rate: THB per 1 unit of foreign currency at time of entry
  - paid_amount: track how much of AP balance has been settled

SQL TO RUN ON PRODUCTION (in order):

  ALTER TABLE expenses
    ADD COLUMN IF NOT EXISTS currency_code TEXT NOT NULL DEFAULT 'THB';

  ALTER TABLE expenses
    ADD COLUMN IF NOT EXISTS exchange_rate DECIMAL(15,6) NOT NULL DEFAULT 1;

  ALTER TABLE expenses
    ADD COLUMN IF NOT EXISTS paid_amount DECIMAL(15,2) NOT NULL DEFAULT 0;

RISK: Very low.
  - IF NOT EXISTS: safe to re-run, no error if column already exists.
  - DEFAULT values: no existing rows affected.
  - Additive only: no existing columns modified or dropped.

VERIFY AFTER RUNNING:
  SELECT column_name, data_type, column_default
  FROM information_schema.columns
  WHERE table_name = 'expenses'
    AND column_name IN ('currency_code', 'exchange_rate', 'paid_amount')
  ORDER BY column_name;
  -- Expected: 3 rows

ROLLBACK (only with authorisation + simultaneous code revert):
  ALTER TABLE expenses DROP COLUMN IF EXISTS currency_code;
  ALTER TABLE expenses DROP COLUMN IF EXISTS exchange_rate;
  ALTER TABLE expenses DROP COLUMN IF EXISTS paid_amount;

RELATED CODE FILES:
  server/routes/expense-routes.ts — reads/writes these columns via raw SQL
  client/src/pages/purchases/expense.tsx — sends currencyCode/exchangeRate
  client/src/pages/purchases/expense-list.tsx — displays outstanding/total

NOTE: ALTER TABLE code was REMOVED from expense-routes.ts (commit cd21f4f9)
      after unauthorised auto-run was discovered. The columns now exist
      only because they were run once on dev during development.
      Production requires manual authorised run of the SQL above.
